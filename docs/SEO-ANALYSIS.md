## Goal

Prioritize higher-value enquiries: weddings, corporate events, large celebration cakes, event cakes, and requests from caterers/event partners.

## Strategic conclusion

The best commercial focus is not generic “cake shop Munich”. The stronger lead-intent terms are:

1. wedding cakes / Hochzeitstorten
2. corporate cakes / Firmentorten
3. event cakes / Eventtorten
4. cakes and sweet pieces for caterers/event partners
5. custom cakes / individuelle Torten

## Multilingual SEO note

The current website uses one URL per page with client-side language switching. This is acceptable for users, but not ideal for strong bilingual SEO. For best German + English SEO later, create separate URLs such as:

- `/cakeshop` for German
- `/en/cakeshop` for English

Then add hreflang. This is not part of this update because it would be a larger structural change.
